image 546d530bb68a), not by reading code. The two scripts that did it are in
the repo and now run every night after the smokes:

- `frontend/api-audit.mjs` — 78 checks over every API endpoint group, with a
  fresh 30-second upload of real speech (`frontend/audit-assets/audit-30s.mp3`)
  transcribed on the GPU, a real render, and everything it made deleted after.

  Chromium and in WebKit (Safari's engine), with screenshots.

Together with the existing gates (smoke 33 steps, phone smoke, full-flow
regression, 874 backend tests) this is the coverage the release rule asks for.

## What was broken and is now fixed

1. **Blank selects.** "Clips per episode" and "Import older episodes" on Feeds,
   and "Clips" in the Studio batch panel, showed nothing. Their options carried
   numbers where the Material select compares strings, so no option ever
   matched. Every numeric option is a string now. Commit of 2026-09-02 evening.
2. Earlier the same day (separate commits): the Safari drag bug, silent save
   failures, the layer-order export bug, retyped words not reaching captions,
   the friendly page for a dead share link, the panel reshuffle Afiya asked for.

## Observed once, not reproduced

The smoke project was found at 16:9 on the server while the screen had shown
1:1 after a shape switch. Six rounds of rapid switching and a full smoke with
the database polled every two seconds did not reproduce it. The UI audit now
checks the server's shape after every switch, so a recurrence will fail the
nightly with the exact step named.

## Still open (known, not bugs found by this audit)

- 16:9 banner / bigArt starter templates place the caption band across other
  layers; the remap needs a 16:9-aware layout.
- No pagination on the projects list; the trash sweep runs on every list call.
- Slider drags send one PATCH per tick.
- Loudness is measured without sound effects mixed in.
- Owner decisions: the Unraid `storage` SMB share is guest-writable; Dozzle
  (:8092) is unauthenticated.

## How to run by hand

```
cd frontend
node api-audit.mjs --base-url http://192.168.1.58:8099 --username mujin --password … --assets audit-assets
node ui-audit.mjs  --base-url http://192.168.1.58:8099 --username mujin --password … --assets audit-assets [--engine webkit] [--shots DIR]
```

Never run either at the same time as a smoke on the same account: they create
and delete projects, and the smoke opens the newest one.
